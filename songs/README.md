# 曲

本体で鳴らす曲のデータです。**著作権が切れた曲のメロディだけ**を使います（誰かが作った編曲や、日本語の歌詞には著作権が残っている場合があるので使わない）。

## データの形

本体のプログラムでは、`py firmware/shinkokyu/make_songs.py` で、ここの JSON から `firmware/shinkokyu/songs.h` を作ってから書き込む。

```json
{
  "title": "曲名",
  "bpm": 100,
  "phrases": [
    [["D4", 1], ["G4", 2], ...],
    ...
  ]
}
```

- `phrases` の1つ ＝ **1回の吐く息**で吹くフレーズの目安（本体は、吹き続ければ次のフレーズへ進む）
- 音は `[音名, 拍数]`（例：`["G4", 2]` ＝ ソの音を2拍）
- 本体の小型スピーカーは低い音が出にくいので、本体では1オクターブ上げて鳴らす
