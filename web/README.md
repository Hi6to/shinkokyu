# PC のページ

| ファイル | 中身 |
|---|---|
| [smoke.html](smoke.html) | **煙の画面**（S05）。作業中に煙のかたまりがたまる（いっぱいで曲の音の数＝32個）。本体で吹くと、音が1つ鳴るたびに、息の入る下の側から煙が1つ「ぽっ」とはじけ、曇り空が青空と朝日に変わっていく。もやもやを打ち込むと、煙のかたまりに言葉が付き、曲の途中と最後の音で消える。1曲吹き終えると「一服おわり」と息の長さ。本体がなくても、スペースキーを押している間を「吹いている」として試せる |
| [retro.html](retro.html) | 煙の画面の**レトロ版の試作**（ドット絵・少ない色・カクッとした動き）。数字キー 1〜9 で効果を入れる・切るして見比べる。H で操作の表示 |
| [index.html](index.html) | 本体モニター（S01）。気圧の差・息の状態・曲の位置・息の記録を見る |
| [device.js](device.js) | 本体と Web Bluetooth でつながる部品。本体が送る行の形も、ここの先頭に書いてある |

## 開き方

Web Bluetooth は `http://localhost` か `https` でしか動かないので、リポジトリのいちばん上でサーバーを動かして、Chrome か Edge で開く（曲のデータ `songs/` も読むため、`web/` ではなくリポジトリ全体を配る）。

```bash
py -m http.server 8020 --bind 127.0.0.1
```

- 煙の画面：http://localhost:8020/web/smoke.html
- 本体モニター：http://localhost:8020/web/index.html

煙の画面のキー：スペース＝吹く（試す）、F＝全画面、H＝設定（本体をつなぐ・たまる速さ・もやもや）
