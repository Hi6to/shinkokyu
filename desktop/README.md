# シン呼吸 デスクトップ（作業中の画面の右下で育つアプリ）

> 11/12：**初めの見せ方は「右下の小窓で育てる」**（下の「見せ方：右下の火の子」）。キャラクターは**火の子のまま**（11/12 に決めた。G01 は終わり）。下のすぐの説明（煙・煙メーター）は、切りかえで残している**前の見せ方（画面全体の煙）**のもの。今の決まりは [README.md の「最新の決まり」](../README.md#最新の決まり1112-時点ほかの文書とずれていたらここが正しい)

作業中の画面の一番手前に、透明な窓で煙を出す。中身の画面は [../web/retro.html](../web/retro.html) を `?overlay=1` で開いたもの（ブラウザ版と同じものを使い回す）。

- **煙**：作業の邪魔にならないよう、画面の端（下・左右・上）にだけたまる。窓はマウスの操作を素通りさせるので、下の画面はふつうに使える
- **通知領域（時計の横）のアイコン**：小さな雲が、たまり具合に合わせて下から白くなる。**押すと操作パネル**が出る（ボタンを押しても閉じない。外を押すか × で閉じる）。右クリックは「終わる」だけ
  - 操作パネル：煙の表示・本体をつなぐ・**もやもや（言葉を打ち込むと、煙の雲に書かれる。ブラウザは要らない）**・音量・たまる速さ・いっぱいにする・晴れる様子を早送り・スペースキーで吹く（ためし）・終わる
- **Windows の通知**：煙がいっぱいになったら「そろそろ一服しませんか」を1回だけ（**押すと、煙を隠していても表示に切りかわる**）。吹き終えたら「一服おわり」（押すと早送り）
- **文字は「メッセージの窓」**（黒い箱＋白い枠）に出す。どんな壁紙の上でも読める。**自分で消える**（10秒）ほか、**押す・作業を始める（キーやマウスにさわる）・吹き始める**でも消える
- **吹いている間**は、晴れていく様子をその場で見せる（発表用）。最後の太陽は出さない
- **戻ったら早送り**：一服の間に PC から30秒以上離れていた人が、終わったあとに PC にさわると、全部の煙がスーッと消えていく様子を約5秒の早送りで見せて、「おかえりなさい」を出す（実際の吹き方には合わせない）
- **本体**：「本体をつなぐ」で、名前が Shinkokyu で始まる本体に自動でつなぐ（選ぶ画面は出ない）。休憩場所まで Bluetooth が届かずに切れても、戻ってくれば5秒ごとに自動でつなぎ直す

## 見せ方：右下の火の子（11/08。初めはこちら）

画面全体には煙を出さない。**右下の小窓に「火の子」**がいて、一服のたびに育つ。結果は**右の吹き出し**（LINE の通知のように下から積む）で知らせる。前の見せ方（画面全体の煙）には、操作パネルの「見せ方」ボタン・通知領域の右クリックで戻せる。

- **育ち方**：本体に吹いたときだけ育つ（キーボードの「ためし」では育たない）。4秒より長い息（ゆっくり長く）ほどあたたまる（1回で8まで）。**強く吹きすぎる**と（息の強さの山が 70 Pa 以上。ふつうの長い息は 12〜58 Pa）火の粉が散って、ほとんどあたたまらない（一服の初めの1回だけ、吹き出しで「そっと 長く」と知らせる）。**キーボードで吹いた1本では育たない**（11/08 に直した。前は1本ぶんのおまけが入っていた）。1曲吹きおえると「1本」でおまけ。愚痴のラベルは**薪**になり、燃えて火があたたまる。本体2台がつながっているときは、2人の火をよせて**焚き火を囲む**（あたたまり方が1.5倍）
- **段**：火種 → ちび火 → 灯 → ランタン → 焚き火（ゆっくり長い息で1日2〜3回なら、3〜4日で焚き火）。右下の小窓に段の名前と、次の段までの点（5つ）
- **休憩と休憩をつなぐ**（11/08）：1回の休憩で終わらず、次の休憩に続くようにする
  - **次の目印**：1本おわるたびに、結果の吹き出しの最後に「〔ランタン〕まで あと 2本 ぐらい」（その人の最近5本のあたたまりで見積もる）。次の休みどきの吹き出しにも「前の火の つづき：〔ランタン〕まで あと 2本」
  - **焚き火のまわりが、にぎやかになる**：焚き火に着いたあとは、1本ごとにまわりに1つふえる。石の輪 → 丸太のいす → やかん → 月 → テント → ほたる → そのあとは夜空の星が1つずつ（16個まで。その先はまだ決めていない）。焚き火に着いた1本は、段が上がったことがごほうびなので、ふえるのは次の1本から。減らない。次にくる物も「つぎの 1本で、〔テント〕が たつよ」と先に知らせる
- **決まり**（11/09：「ゲームではない」はやめて、放置・育成ゲームにすると決めた。下の決まりを残すかはチームで決める。キャラクターは火の子のまま：11/12）：点数・連続日数・自己ベスト・ランキングは出さない。育ったものは減らない。休まなかった日に弱ることもない（煙がたまると、うとうとするだけ）
- **右下の小窓**：火の子のまわりの灰色の煙＝作業でたまったもやもや。7割をこえると、火の子がうとうとする。そっと吹いている間は明るく大きくなり、火の粉がまっすぐ上る。強すぎると、目をぎゅっとつぶって火の粉が左右に散る。愚痴のラベルは、**言葉の札がついた薪**になって上から落ちてきて、**左下に積まれる**（3本まで。積んである間は、薪に白い帯＝札）。曲が進んでラベルが消えるたびに、**薪が札ごと1本ずつ弧をえがいて火へ飛びこみ**（札は橙になって消える）、炎がぐっと大きく橙色になって火の粉が噴き上がる**（枠も橙に。1本 約1.8秒で、いくつか一度に燃えても1本ずつ順に）。札の言葉は、煙の上の言葉と同じ決まり（席にいないとき・出さない設定のときは、言葉のない札）。**本体が2台つながると、2つの火が寄ってきて（約1.5秒）、顔が2つの大きな焚き火**になり、名前が「ふたりの焚き火」になる
- **右の吹き出し**：90年代のレトロな文字で、1文字ずつ「シュッ」と出る。マウスは素通り。出すのは、休みどき（理由の1行つき）・一服の結果・段が上がった・お誘い（「火を わけに いこう」）・本体が2台そろった・愚痴を薪にした（言葉は、煙の上の言葉と同じ決まりで出す。出さない設定なら「もやもや」とだけ）・強く吹きすぎた、のとき。**休憩の実験の間は出さない**
- **戻ったとき**：席を離れている間（PC を30秒さわらない）は、右下の火の子を離れる前の姿のまま止めておく。戻って PC にさわると、育っていれば「前の姿 → 点滅 → 今の姿」の演出（約4秒）と、吹き出し「おかえり。火が 少し 大きく なりました」（段が上がっていれば「〔ランタン〕に なったよ」も。焚き火のまわりに物がふえていれば「焚き火のまわりが 少し にぎやかに なりました」）。離れている間の吹き出しは、戻ってからまとめて出す
- **火の子のためし（約55秒・記録しない）**：操作パネルか、通知領域の右クリックから。仮の火の子で、休みどき → そっと吹く → 強く吹く（火の粉が散る）→ 1本おわり（次の目印）→ お誘い（火を分ける）→ 2台で焚き火 → 話した愚痴（「長いレビュー」「急な残業」）が札のついた薪になって1本ずつ加わる → ふたりで吹くと、札ごと火へ飛びこむ → ふたりで1本（焚き火に着く）→ 次の1本で石の輪 → 先まで進めた、にぎやかな焚き火、を順に見せる（発表の練習・見た目の確かめ用。本当の火の子は変わらない）
- 形と色：`desktop/hinoko.js`（ドット絵）、育ち方：`desktop/fire.js`、吹き出し：`desktop/notice.html`。覚えている育ち具合は、アプリのデータの場所の `settings.json` の `fire`
- 煙の画面（`web/retro.html`）は、本体とのつなぎ・曲の進み・席の札を受け持っているので、ゲームの見せ方でも透明な窓として動かしたまま（煙を描かないだけ）
- **まだのこと**：休憩場所で Bluetooth が切れると、その間の息は PC に届かない（本体が息をためて、つながり直したら送る仕組みは、まだない）

## 動かし方

```bash
cd desktop
npm install
npm start
```

- **チームの人の PC**：`setup.cmd` をダブルクリックすると、部品を入れて（`npm install`）、デスクトップに「シン呼吸」と「シン呼吸 休憩の実験」のショートカットを作る（Node.js が要る）
- 初めての PC では `npm install` で Electron（本体は展開すると約350MB）をダウンロードする
- **Hi6to の PC**：リポジトリが OneDrive の中にあるので、Electron の本体は OneDrive の外（`%USERPROFILE%\apps\shinkokyu-electron`）に置いてある。`start.cmd` をダブルクリックすると、そちらを使って起動する（OneDrive が大きなファイルを同期しないように）
- 煙の画面の中身は、アプリの中の小さなサーバーが `web/` と `songs/` を配っている（外には出ない）

## 記録（休憩のタイミングを数字で決めるための土台）

アプリを動かしている間、作業のリズムと一服のようすを **この PC の中だけ** に記録する（外には送らない）。

- 場所：`%APPDATA%\shinkokyu-desktop\logs\日付.jsonl`（操作パネルの「記録のフォルダを開く」で開ける）
- **何を打ったか・どのキーを押したかは記録しない**。数えるのは回数と間隔だけ（消すキー＝Backspace・Delete かどうかだけ区別する）
- 1分ごとに1行（`type: "rhythm"`）

| 項目 | 意味 |
|---|---|
| keys / corr / corrRate | キーを押した回数・消すキーの回数・打ち直しの割合 |
| ikiMed / ikiCv | キーを打つ間隔（ふつう、ms）と、そのばらつき |
| pauses / longPauses | 手が止まった回数（2〜30秒／30秒以上） |
| mouseDist / mouseEff / clicks | マウスの動いた量・まっすぐさ（1に近いほど迷いがない）・クリック数 |
| activeSec | 操作のあった秒数 |

- できごとの行：`app_start`・`app_quit`・`notify`（休憩の通知）・`session_start`・`session_end`・`breath`（1回の息の長さ）・`song_done`（その一服の息の並び）・`away`（2分以上 PC から離れていた時間）
- 使っている部品：[uiohook-napi](https://github.com/SnosMe/uiohook-napi)（キーボードとマウスの動きを、どのアプリを使っていても受けとる）

## 休憩の実験（約10分）

深呼吸のあとに集中が戻るかを試す機能（やり方は docs/EXPERIMENT.md）。

- **始め方**：デスクトップの「シン呼吸 休憩の実験」（`setup.cmd` で作る）、キー **Ctrl+Alt+R**（どのアプリを使っていても効く）、操作パネルの「始める」、通知領域のアイコンの右クリックのメニュー
- **選ぶ**：スペースキーで「休憩の実験（約10分）」、2 キーで「反応テストだけ（3分）」
- **実験の流れ**：反応テスト3分（まんなかに数字が出たら、すぐスペースキー）→ くじで3分の過ごし方（深呼吸＝本体に吹く／呼吸しないで休む／休まない）→ 反応テスト3分 → 結果
- **本体がないとき**も実験はできる。くじは「呼吸しないで休む」「休まない」の2つから（基板が2台しかないため）
- 窓は画面いっぱいに出る。テスト中に入力が外れると、画面の下に赤い字が出る
- **強制的に終わる**：窓の右上の「× やめる（Esc）」。窓が反応しないときは、操作パネルの「実験をやめる」か、通知領域のメニューの「休憩の実験をやめる」
- 窓が開いている間は、キーボードとマウスを見る仕組みを止める（反応テストのキーの届き方に影響しないように）。煙の画面も、休憩の通知や「一服おわり」の演出を出さない。深呼吸の3分の間は、曲が終わっても最初からつづく
- 記録の行：`trial_open`・`trial_start`（mode が trial＝実験・solo＝反応テストだけ、device＝本体がつながっていたか）・`pvt`（kind が pre＝はじめ・post＝過ごしたあと、pair で同じ回を結ぶ、lost＝入力が外れていた回）・`lottery`・`activity_start`・`activity`（過ごし方の3分に本体に吹いた息）・`trial_end`・`trial_cancel`
- 本体の音量は 0〜8（0 は音なし）。`activity_start` の行に、そのときの音量が残る
- くじの残りと、日ごとの回数は `%APPDATA%\shinkokyu-desktop\experiment.json`
- ためし：`desktop/trial.html?quick=1` をブラウザで開くと、各20秒の短い版が記録なしで動く。アプリでは `--trial --quick` で開く（記録には quick の印が付く）

## 休みに行く口実（理由の1行と、席の札）

吸わない人には、休みに行く口実がない。そこを2つで埋める（docs/IDEAS.md）。

- **理由の1行**（[reason.js](reason.js)）：煙がいっぱいになったときの通知と煙の画面の窓に、理由を添える
  - つづけて作業した時間：5分以上 手が止まった所（または一服の終わり）から数える。50分を超えたら「国の目安は 1時間ごとに 10〜15分の休み」も出す
  - ふだんとのちがい：直近15分を、過去7日のその人の真ん中の値と比べ、一番ずれた1つ（打ち直し・手が止まる回数・打つ間隔のばらつき・マウスの迷い）が1.2倍以上なら出す。記録が1時間分たまるまでは出さない
  - 言い方は見たままの事実だけ（「集中が落ちています」とは言わない）
  - 操作パネルの「煙」の下にも、いまの値が出る。通知の記録（`notify`）にも、そのときの値が残る
- **席の札「シン呼吸中」**：画面のまん中に大きく出す（煙を隠していても出る）
  - 出す：本体で一服を始めたとき、操作パネルの「一服に行く」、通知領域のメニューの「一服に行く」
  - おろす：20秒以上 PC をさわらなかったあとに、さわった（戻ってきた）／PC の前で吹き終わった／操作パネルの「札をおろす」／30分たった
  - 記録の行：`sign_on`・`sign_off`（何分出ていたか）

## 一服のお誘い（11/07）

- **本体の曲送りボタン（SW1）を長押し**すると、この PC に「一服のお誘いが届きました／ひと息入れに行きませんか」と通知が出る。煙を隠していても、10秒だけ画面にも出る
- 同時に、つながっている本体と Sense 版の LED が、10秒 紫に点滅する（`LIGHT 10`）
- 試すとき：操作パネルの「一服のお誘いを試す」か、通知領域のメニューの「一服のお誘いを試す」
- 誰からかは出さず、記録も `invite`（いつ・どこから押したか）だけ。5秒の間に何度押しても1回
- 今は**同じ PC の中だけ**で受け渡す（別の人の PC へ送る仕組みはまだない）。振動モーターは使わず、光で知らせる

## もやもやを話す（声を煙のラベルにする）

話した愚痴を、AI が短い言葉（2〜6文字）にして、煙のラベルにする。**声も文字も PC の外に出ない**（全部 PC の中で動かす）。

- **話し方**：操作パネルの「押している間 話す」（はなすと終わる）か、キー **Ctrl+Alt+M**（押すと始まり、もう一度で終わり。30秒で自動で終わる）
- **言葉はいくつでも（3つまで）**：話題がいくつかあれば、雲もいくつか出る。例：「最近肩こりがひどくて、腰も痛いし、寒くて…」→「肩こり」「腰痛」「寒さ」
- パネルの「もやもや」の下に、最後に聞きとった文が出る（記録には残さない）。`voice.json` に `"compare": "small"` と書くと、もう1つのモデルの聞きとりも並べて出す（比べるとき用。煙にはしない）
- **声の基板（Sense 版）**：操作パネルの「声の基板（Sense 版）をつなぐ」で Bluetooth でつなぐと、PC のマイクの代わりに基板のマイクで録る（[sense-mic.js](sense-mic.js)、基板のプログラムは [firmware/sense_mic/](../firmware/sense_mic/)）。切れたら5秒ごとにつなぎ直し、その間は PC のマイクを使う。基板の D1 にボタンをつなげば、そのボタンを押している間だけ録る
- **流れ**：録る（16kHz の WAV）→ Whisper で文字にする（[voice/stt_worker.py](voice/stt_worker.py)）→ AI で短い言葉にする（[voice/label.js](voice/label.js)）→ 煙のラベル。話し終わってから約2〜3秒
  - 例：「えっと、部長がまた仕様を変えてきたんですよ。もう三回目です」→「仕様変更」
  - 役職（部長・上司など）や人の名前は、言葉に入れない（煙はまわりからも見えるため）
  - 声がない（音が小さいまま）ときや、Whisper が無音から作りがちな文（「ご視聴ありがとうございました」など）は、聞きとれなかった扱いにする
- **記録**：`voice_start`・`voice_label`（話した長さ・文字にした時間・AI の時間・文字数だけ。**話した中身は残さない**）。録った WAV は使い終わったらすぐ消す
- **要るもの**（なければ「部品が入っていません」と出る）
  - Whisper：`%USERPROFILE%\venvs\shinkokyu-voice`（作り方は [firmware/README.md](../firmware/README.md) の「声を文字にする」）。モデルは base（はじめて使うときに約140MB をダウンロードする）
  - 短い言葉にする AI：Ollama と Sarashina2.2 3B（`%USERPROFILE%\apps\ollama`。アプリが自動で起動する）。ない PC では、言いよどみを取って先頭を切り出す簡単なやり方になる
- **設定ファイル**（`%APPDATA%\shinkokyu-desktop` に置く。GitHub には上げない）
  - `voice.json`：ふだんは `small`＋雑音を消す＋言葉のヒント（11/07 に base から変えた。10秒の声を約4秒）。`{ "model": "base", "denoise": false }` で速い方に戻す。`"hotwords": false` で言葉のヒントを使わない
  - `llm.json`：大学の LLM など、OpenAI と同じ形のものに切りかえる。`{ "api": "openai", "baseUrl": "https://…/v1", "model": "モデルの名前", "apiKey": "…" }`（API キーはこのファイルにだけ書く）

## 煙の上の言葉の見せ方と、右下の煙メーター（11/07）

- **煙の上の言葉（もやもや）は、席にいるときだけ見せる**：席の札が出ている間や、1分 PC をさわっていない間は、まわりの人が画面を見るので、言葉を消してただの煙として描く。「「急な残業」も、晴れました」のような、言葉が入る知らせの文も出さない。戻って PC にさわると、また見える
  - 操作パネルの「煙の上の言葉」で選べる：自分がいるときだけ見せる（はじめの設定）／いつも見せる／見せない
- **右下の煙メーター**：窓の枠もタスクバーのボタンもない、小さな浮いた絵。雲がたまり具合に合わせて下から白くなる（外枠は明るい灰色、まだの所は暗い灰色、たまった所は白。雲の1行ずつ変わる）。文字や％は出さない（マウスを乗せると、何％かが出る）。いっぱいになると、3秒に1回カクッとふるえる
  - 「煙を隠す／煙を出す」ボタンで、画面全体の煙をすぐに切りかえられる（操作パネルの「煙を表示している」と同じ）
  - 吹いている間・席の札・知らせなどで一時的に出ているときに「煙を隠す」を押すと、その間はもう出さない（次の一服や知らせから、また出る）。吹きかけてやめた一服は、90秒吹かなければ終わりにする（11/07：ずっと一服中の扱いになり、隠してもすぐ出てきたため）
  - 雲の所をつかんでドラッグすると、好きな場所に動かせる（場所は覚えておく。画面の外になったときや、通知領域のメニューの「煙メーターを右下に戻す」で右下に戻る）
  - 大きさは「小・ふつう・大・特大」から選べる（操作パネルの「煙メーターの大きさ」か、通知領域のメニュー）。右下の角を動かさずに広がる（縮む）
  - 雲の所を押すと（動かさずに離すと）操作パネルが開く。マウスを乗せると出る「×」でメーターを消せる。操作パネルの「右下の煙メーター」と、通知領域のメニューで、いつでも出す・消すを切りかえられる
  - 出すのはたまり具合だけ（言葉は出さない）
- 設定（メーターを出すか・言葉の見せ方）は `%APPDATA%\shinkokyu-desktop\settings.json` に覚えておく
