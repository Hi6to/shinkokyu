## ひとことで

**吸わなくても、気軽にひと息つける。** 休みに行く「口実」と「相手」、そしてほっとできる「休み方」を、くわえて吹く専用の本体と、作業画面の右下で育つキャラクターで届ける。

## 説明文（そのまま使える版）

11/12 版。外に出す文なので「一服」は使わない。

> たばこを吸う人は、仕事の合間にたばこ休憩で席を立てます。吸わない人には、表立って休む理由も、一緒に休む相手もいません。国のガイドラインでも、パソコン作業は1時間ごとに10〜15分の休止が目安とされていますが、口実がなければ休みにくいのが現実です。
>
> シン呼吸は、たばこ休憩からニコチンを除いたものを、吸わない人に届けるプロダクトです。休みに行く「口実」と「相手」、そしてほっとできる「休み方」を提供します。
>
> **口実**　休みどきには「55分つづけて作業しています。打ち直しが、ふだんの1.4倍です」のように、続けて作業した時間と作業のリズムの乱れから、なぜ今休むのかを数字で示します。席を外している間は画面に「シン呼吸中」の札を出し、まわりにも休憩中であることが伝わります。
>
> **相手**　本体のボタンを長押しすると、同僚に「ひと息入れに行きませんか」と届きます。本体の近くで話した愚痴は、AI が「肩こり」「急な残業」のような短い言葉にし、吹けば消えていきます。紙に書いた怒りを捨てると気持ちが収まるという研究から着想した、喫煙所の雑談の代わりです。
>
> **休み方**　本体は、たばこのようにくわえて吹く専用のデバイスです。画面がないので、休憩中にスマホやメールに流れません。吐いている間だけ本体の光の色が変わっていき、深呼吸をしようと頑張らなくても、ゆっくり長く吐く呼吸になります。音を鳴らせば、吐いている間だけ曲が進みます。作業画面の右下では、吹くたびにキャラクターが育ち、席に戻ると育った姿が迎えてくれます。
>
> 職場で安心して使えるよう、声も文字も PC の外には出しません。声を文字にする AI も、短い言葉にする AI も PC の中で動き、記録に残すのは回数と時間だけです。また、反応テストと、くじ引きで休み方を比べる実験を自分たちで行い、「時間がたっただけで戻った」分と分けて、深呼吸で集中が戻るかを確かめています。
>
> 吸う人だけが休める職場から、だれもが前向きに休める職場へ。シン呼吸は、そのための新しい休憩のスタンダードをつくります。

## 背景と課題

- 喫煙者は「たばこ休憩」で、仕事の合間に席を立てる。1回の離席は平均 **約9分48秒**（BATジャパン、2023）。その約7割は、吸わない人に後ろめたさも感じている
- 国の目安：パソコン作業は「一連続作業時間が1時間を超えないようにし、次の連続作業までの間に10分～15分の作業休止」（厚生労働省の VDT ガイドライン。2019年の情報機器作業のガイドラインでも考え方は同じとされる。**新しい原文の数字は発表の前に確かめる：TASKS.md R18**）
- 喫煙者の一服は、たまたま国の目安とほぼ同じ長さ。吸わない人は、その10分を取れていない
- **課題：吸わない人には、休みに行く口実も、一緒に行く相手もない**

## 目的

吸う人も吸わない人も、だれもが前向きに休める「休憩のスタンダード」をつくる。

- スタンダードにするのは**休み方の型**：理由が示される → 本体でゆっくり長く吐く（数分）→ 送り出されて作業に戻る
- **いつ休むかは決めつけない**。国の目安を出発点に、その人の作業のリズムで早める（「1時間」と決めると、仕事や人に合わないため。11/06 に決めた）

## 提供するもの

| 柱 | 中身 | 状態 |
|---|---|---|
| **口実**（なぜ今、休んでいいのか） | **理由の1行**：休みどきの吹き出し・通知に「55分つづけて作業しています。打ち直しが、ふだんの1.4倍です」。50分を超えたら国の目安も添える | 作った |
| | **席の札「シン呼吸中」**：吹き始めたら画面に大きく出し、戻るとおりる。吸わない人の空いた席がサボりに見えないように（アンケートでは「目立つので、ないほうがいい」45%。見せ方は見直しの余地あり） | 作った |
| | 休みどきを、作業のリズムの乱れで早める | 作る予定（R16） |
| **相手**（だれと休むか） | **お誘い**：本体の ▶ を長押しすると、PC に「ひと息入れに行きませんか」と通知が出て、本体と Sense 版の LED が紫に点滅する（振動モーターは使わない） | 作った（今は同じ PC の中だけ） |
| | **2台で吹く**：本体が2台つながると、2人のキャラクターが寄って一緒に育つ（今の見せ方では「ふたりの焚き火」、育ち方 1.5倍） | 作った |
| | **愚痴を吹き消す**：本体の近くで話すと、声の基板（Sense 版）が録り、AI が短い言葉（「肩こり」「腰痛」など3つまで）にする。吹くと消える（今の見せ方では、言葉の札のついた薪が火に入る）。喫煙所の雑談の代わり | 作った（会話の距離での聞きとりを調整中） |
| **休み方**（どう休むか） | **くわえて吹く専用の本体**：画面がない。**吐いている間だけ LED の色が変わっていき**、頑張らなくてもゆっくり長く吐く呼吸になる。**音楽は自由に設定できる**（鳴らすなら、吐いている間だけ曲が進む：笛の音、アメイジング・グレイス） | 本体・音は作った。LED の色の変化は作る予定（L01。今は吐いている間 青） |
| | **右下で育つキャラクター（放置・育成ゲーム）**：ゆっくり長く吐くほど育つ。強く吹きすぎると育たない。次の段までの目印を出し、休憩と休憩をつなぐ。点数・連続日数・ランキングは出さない。キャラクターは**火の子** | 作った |
| | **戻ったら育った姿**：席を離れている間は止めておき、戻ると「前の姿 → 今の姿」と「おかえり」で送り出す | 作った |

愚痴を吹き消す着想のもと：名古屋大学の研究で、怒りの原因を紙に書いて**捨てる**と怒りが収まり、取っておくと収まらなかった（Kanaya & Kawai, *Scientific Reports*, 2024）。シン呼吸は、この「書いて捨てる」を「話して、短い言葉にして、吹いて消す」に置きかえた。**画面の上で同じ効果があるかは確かめていない**ので、「着想のもと」として紹介する。

## 強み（ほかとのちがい）

1. **たばこの「形と儀式」を借りた専用の本体**：くわえて、吐く。画面がないので、休憩中にスマホやメールに流れない
2. **呼吸を頑張らせない**：呼吸法アプリは「深く吸って」と頑張らせる。シン呼吸は、吐いている間だけ光の色が変わる（音を選べば曲が進む）手ごたえで、結果として長く吐く呼吸になる
3. **作業画面の右下で育つ**：別のアプリを開かなくても、休みどきとキャラクターが目に入る。放置・育成ゲームなので、休憩と休憩がつながる（クリックは下の画面に素通り）
4. **口実を数字と札で示す**：理由の1行と「シン呼吸中」の札。吸わない人に足りない「休む理由」を、自分にもまわりにも見える形にする
5. **愚痴を吹き消す**：喫煙所の「愚痴を言って煙と流す」を形にした。研究に基づく着想
6. **プライバシーに配慮した作り**：声も文字も PC の外に出ない（声を文字にする AI も、短い言葉にする AI も PC の中で動く）。記録は回数と時間だけで、打った文字や話した中身は残さない。画面の言葉に人の名前や役職は出さない。席にいないとき（札が出ている間など）は、言葉を消す
7. **自分たちで確かめている**：3分の反応テスト（集中や眠気の目安として研究で使われる PVT の短い版）と、くじ引きで比べる実験（深呼吸／呼吸しないで休む／休まない）。「時間がたっただけで戻った」分と分けて、深呼吸の分を見る。本体は息の長さや回数も測る。事前アンケート 60件、使ってもらった人のレビュー（REVIEW_SURVEY.md）
8. **ハードウェアまで自作**：専用の基板を設計して発注し、気圧センサーで息を検出。LED と、自由に設定できる音楽（本体のスピーカー）で返す。声の基板から Bluetooth で声を送る

なぜ休み方が呼吸なのか（理由の洗い出しと、反対の研究も含めた見直し）は [WHY_BREATH.md](WHY_BREATH.md)。

## 審査基準との対応

審査基準は4項目（各5点）。4. プレゼンテーション力は Award Day だけ。

| 基準 | 見られること | シン呼吸で答えること | まだ足りない所 |
|---|---|---|---|
| **1. 問題着眼点・着想点** | 解いている問題が明確で新しいか、または解き方が新しいか | 課題「吸わない人には、休みに行く口実も相手もない」。解き方は、たばこ休憩からニコチンを除いたもの（口実・ひと息・仲間）を、吸わない人に渡すこと。くわえて吹くと光が変わる本体・右下で育つキャラクター・愚痴を吹き消すのは新しい | 「たばこ休憩はずるい」だけだと、よくある話に聞こえる。**「吸わなくても、気軽にひと息つける」と言い切る** |
| **2. 実行・実現可能性** | 想定する使う人がはっきりしているか、まねされにくいか、広げられるか | 使う人：職場の、たばこを吸わないデスクワーカー。まねされにくさ：専用のハード＋息で光と育成が進む仕組み、仲間が増えるほど価値が上がるお誘い。広げ方：本体は使う人が自分で買う（11/08 に決めた。お金の流れの1枚は見送り） | アンケートでは「会社や学校が用意してくれたら」47%・「自分で買う」7%。質疑で聞かれたときの答えを用意する |
| **3. 完成度・動作性** | 作ったもので、掲げた課題が解決しているか（4点：解決することが論理的に示された、5点：実証された。満点はプロダクトにわくわくする） | 口実（理由の1行・札）、休み方（本体・育成・戻ったときの姿）、相手（お誘い・2台・愚痴）が動く。休憩の実験（反応テスト＋くじ引き）と、4人のレビューで「解決」を示す | LED の色の変化（L01）。7日分の実験データ（11/7〜13） |
| **4. プレゼンテーション力** | 伝わるか、心が動くか | 発表は7分。審査員に吹いてもらうことはしない。Hack Day から変わった所は話さない。遥さん・菜月さんの「ある日」を2人で演じ、本体の光の色を画面にも映す | 台本と練習（11/14 通し） |

## 言い方の注意（チームでそろえる）

| 言わない | 代わりに言う | なぜ |
|---|---|---|
| 「リラックスできる」「疲れがとれる」「健康になる」と言い切る | 「ゆっくり長く吐く呼吸になる」「こういう差が見えた」 | 健康や病気への効果に聞こえる。確かめていない |
| 「作業効率が下がっていることを示す」 | 「作業のリズムの乱れ（打ち直し・手の止まり）を、ふだんと比べて示す」 | 効率の低下は、まだ確かめた判定ではない（アルゴリズム A の当たる割合が出たら言い方を変える） |
| 「国が認めた」「国がすすめる休憩」 | 「国の目安に合わせた」 | 国が認めたものではない |
| 「たばこ休憩が黙認される社会への挑戦」 | 「吸う人だけが休める職場から、だれもが休める職場へ」 | 吸う人を責めているように聞こえ、対立を生みやすい |
| 「愚痴を吹き消すと気持ちが晴れる（論文で証明）」 | 「紙に書いて捨てると怒りが収まる、という研究から着想した」 | 研究は紙の実験。画面の上では確かめていない |
| 「深い呼吸になる」 | 「ゆっくり長く吐く呼吸になる」（息の長さは本体で測っている） | 本体が測れるのは吐く長さと回数 |
