## 注意

- **電池の＋と−は、基板の裏の印刷を見て、テスターで必ず確かめる。** PH のケーブルや電池は、線の色が逆のものもある。逆につなぐと、壊れたり発火したりするおそれがある（基板の Q1 が守る設計だが、つながないのが一番）
- 110mAh の電池は、音を鳴らし続けると数十分くらいの見込み（測ってはいない）。練習中は USB からも電源をとれるようにしておく
- **振動モーター**（11/07：振動モーターは使わないことにした。お誘いは LED と通知。H08 見送り）
  - 振動モーターは XIAO のピンから直接は動かせない（電気が足りず、ピンが壊れるおそれがある）。動かす部品がついたモジュールを使う
  - 電源は電池（J2 の VBAT の側。テスターで電池の電圧が出る方を確かめる）から取る。3V3 は気圧センサーと同じ電源なので、モーターの雑音を入れないために使わない
  - 届いたら、電源のランプ（LED）が付いていないか確かめる。付いていると、眠っている間も電池を使い続ける（110mAh だと数日でなくなる）ので、その LED を外す
  - 同じ形の他社の商品は約 23 × 21mm（基板とほぼ同じ幅）。筒を細くするときは、コイン形のモーターだけを筒の壁に貼り、動かす部品（トランジスタ・抵抗・ダイオード）を線の途中に付ける。モーターは[オーディオファンテックの4個セット（直径10mm・厚さ3mm、PH 2ピン付き）](https://item.rakuten.co.jp/audiofuntech/af-mgmmph2p103104/)が使える（定格 1.5〜3.0V なので、電池につなぐときはプログラムで弱める）
- 組み立ての順番は [PCB_DESIGN.md の「組み立ての順番」](PCB_DESIGN.md#組み立ての順番基板が届いたら)
- ③ 小型化の段階では、専用の基板と、8mm 角の Bluetooth モジュール（例：Insight SiP の ISP1807 など nRF52840 のもの）を使う予定
