## 全体の構成

```
［本体］  気圧センサー（DPS368）・Bluetooth のマイコン（XIAO nRF52840）
  │       LED・アンプとスピーカー（音楽は自由に設定できる）・電池・ボタン3つ・USB Type-C
  │
  ├──Bluetooth──▶ ［PC のアプリ（desktop/、Electron）］
  │                 ・右下で育つキャラクター（放置・育成ゲーム）と吹き出し
  │                 ・休みどきの理由の1行・席の札・お誘いの通知
  │                 ・作業のリズムと息の記録（PC の中だけ）・休憩の実験
  │                 ・発表のとき：本体の LED の色を画面にも映す。音を使う場面は会場のスピーカーへ
  │
［Sense 版］ マイク付きの XIAO ──Bluetooth──▶ PC のアプリ（声を PC の中で文字にして、短い言葉にする）
```

## 機能と、どこで実現するか

| 機能 | どこで | 仕組み |
|---|---|---|
| 吐いたかどうかの判定 | 本体 | 気圧センサーの値から判定する（Hack Day 版の `app/server/breath.py` の処理を、マイコンに移した） |
| **呼吸を促す光** | 本体 | **吐いている間だけ LED の色が変わっていき、ゆっくり長く吐くと先まで進む**（11/09 に決めた。L01 で作る。今は吐いている間だけ青） |
| 音楽（自由に設定できる） | 本体 | 鳴らすときは、吐いている間だけ曲が進む。1フレーズ＝1回の吐く息の目安。音は本体のマイコンで合成する（笛・泡・オルゴール・効果音）。音量 0〜8（0 は音なし） |
| 曲送り・音量 | 本体のボタン（▶・＋・－） | 吹いている間は効かない |
| お誘い | 本体の ▶ の長押し → PC | PC に通知を出し、本体と Sense 版の LED を紫に点滅させる。振動モーターは使わない |
| 育成・吹き出し・理由の1行・席の札 | PC のアプリ | [desktop/README.md](../desktop/README.md) |
| 声を短い言葉にする | Sense 版 → PC のアプリ | Whisper と小さな言語モデルを PC の中で動かす。声も文字も外に出さない |
| 曲の保存 | 本体 | 「音の高さと長さの並び」で、マイコンの中に保存する（1曲あたり数KB） |
| 曲の追加・削除・並べ替え | PC の Chrome | Web Bluetooth で書き込む（優先は低い：S03） |
| 充電 | 本体 | USB Type-C |

## 本体の作り

- 吹き口（ストローの切れ端）→ **小さな息の部屋**（気圧センサー）→ **先端の小さな排気の穴**
  - 排気の穴の大きさで、吹き心地（負荷）が決まる
- 息の部屋と、マイコン・電池を入れる場所は分ける（吐く息の湿気・結露から電子部品を守る）
- 今の形は**案1 の筒（外径 26）**。形と部品は [ENCLOSURE.md](ENCLOSURE.md)、刷るデータは [hardware/print/](../hardware/print/)

## 気をつけること

- **LED の色は、くわえている本人に見える場所で光らせる**。発表では客席から見えにくいので、画面にも同じ色を映す
- **小さなスピーカーは、低い音が出にくい**。音ありのときは、メロディを高めの音域で鳴らす。客席には聞こえないので、発表で音を使う場面は会場のスピーカーに出す
- Web Bluetooth は Chrome・Edge（PC・Android）で使える。iPhone の Safari では使えない
- 利用者が曲を追加できるので、著作権のある曲を入れないよう注意する（試作と発表では、著作権が切れた曲だけを使う）
