### B版で念入りに確かめたこと（2026/10/21）

- **XIAO の端子の位置**：B版の XIAO の型の16個の端子（縁の14個と裏の BAT+・GND）を、Seeed 公式の型（XIAO-nRF52840-SMD）と1つずつ比べた。ずれは全部 0.000mm
- **端子ごとの信号**：XIAO の公式の基板データ（Seeed Studio XIAO nRF52840 v1.3）を B版の基板に重ねて、端子ごとに、真上に来る XIAO の信号が設計どおりかを確かめた（[scripts/verify_xiao.py](../hardware/carrier/scripts/verify_xiao.py)）。D0〜D10・3V3・GND・5V・BAT+ の16個すべて一致
- **はんだ付けしない XIAO の裏の端子（SWD・NFC）**：真下に基板の銅がないことを確かめた（ショートしない）
- **USB-C の口**：基板の端から 0.35mm 内側に収まる（JLCPCB が基板のまわりに縁を付けても、ぶつからない）
- **DRC**：エラー 0。回路図と基板の照合（パリティ）も一致
- **GND のつながり**：B版は XIAO の穴がないぶん裏の配線が増え、GND の面が3か所で孤立していた（アンプのコンデンサ C1・C2・C3 と、J5 の GND）。孤立した所を見つけて線を足すプログラムを作り、ビア1つと線2本でつないだ。そのあと KiCad でも、つながっていない所が 0 であることを確かめた

## 方針

- **A版は XIAO nRF52840 を自分ではんだ付けする**（Bluetooth・電池の充電・3.3V の電源・USB Type-C は XIAO のものを使う）。B版は XIAO も JLCPCB が付ける
- **A版で基板の会社（JLCPCB）に付けてもらうのは、DPS368・MAX98357A と、その周りの小さな部品だけ**
- 試作で確かめる前に注文するので、**動かなかったときに直せる工夫を、できるだけ入れる**
- 動かなかった場合は、段階2（開発ボードを配線でつないで筒に収める）を作る

## 大きさの目標

- 基板：**幅 20.5mm × 長さ 67.5mm**（本体 53.5mm ＋ 首 4mm ＋ センサーのタブ 10mm）、厚さ 0.8mm（筒に収めやすいように薄め）
  - XIAO の幅が 17.8mm で、縁の端子にこてを当てる場所が両側に約1mm ずつ要るため、幅は 19mm から 20.5mm に変えた
  - ボタン（5.1mm 角）3つと、予備の端子の穴の列を入れるため、長さは目標の 50mm より長くなった。タブを切り離せば本体は 53.5mm
- 本体：直径22〜24mm × 長さ約10cm

## つなぎ方（ピンの割り当て）

XIAO nRF52840 のピン（D0〜D10）を、次のように使う。nRF52840 は I2C や I2S（音の信号）に使うピンをプログラムで変えられるので、配線を間違えても直せる場合が多い。

| XIAO のピン | nRF52840 | つなぐ先 | 備考 |
|---|---|---|---|
| D0 | P0.02 | ボタン「曲送り」（SW1） | もう一方は GND。XIAO の内部のプルアップを使う |
| D1 | P0.03 | ボタン「音量＋」（SW2） | 〃 |
| D2 | P0.28 | ボタン「音量−」（SW3） | 〃 |
| D3 | P0.29 | 圧電ブザーの端子（予備の音、J6） | アンプが動かなかったときに、PWM で直接鳴らす |
| D4 | P0.04 | DPS368 の SDA（I2C） | 4.7kΩ のプルアップ（R1） |
| D5 | P0.05 | DPS368 の SCL（I2C） | 4.7kΩ のプルアップ（R2） |
| D6 | P1.11 | 予備（J6） | 振動モーターをつなぐ予定だった（[BOM.md](BOM.md)）→ 11/07 振動は使わないことにした |
| D7 | P1.12 | MAX98357A の SD_MODE（アンプのオン・オフ） | 4.7kΩ（R3）を通す。高い電圧＝オン（左の音）、低い＝止める |
| D8 | P1.13 | MAX98357A の BCLK（I2S） | |
| D9 | P1.14 | MAX98357A の LRCLK（I2S） | |
| D10 | P1.15 | MAX98357A の DIN（I2S） | |
| 3V3 | ― | DPS368 の電源、I2C のプルアップ | |
| GND | ― | すべての GND | |
| 5V | ― | アンプの電源（D1 を通す） | USB をつないでいるときだけ 5V になる |
| （裏）BAT+ | ― | 電池（基板の窓から線でつなぐ、TP1） | 下の「電源」を参照 |

プログラムで音を出すときは、左右の両方に同じ音を入れる（アンプは左の音を鳴らす設定のため）。

## 部品の置き方（上から見て、左が USB の端）

| 場所 | 置いたもの |
|---|---|
| 左の端（0〜21mm） | XIAO（表の上に載せる）。XIAO の下には部品を置かない。裏の BAT+ の真下に窓、そのとなりの裏に TP1 |
| XIAO の先（アンテナの前） | **銅を置かない場所**（XIAO の Bluetooth のアンテナは USB と反対の端にあるため。電波が弱くならないように） |
| 本体の上の縁の列（裏の印刷 LRC〜VIN、SW） | J4（外付けのアンプ用）、J2（電源スイッチ用） |
| 本体の下の縁の列（裏の印刷 GND・D0〜D6、3V3〜SCL） | J6（外付けのボタン・圧電ブザー・予備）、J5（I2C） |
| 本体の真ん中 | アンプ U2 とコンデンサ、スピーカーの穴 J3、電源（D1・D2・Q1・JP1・JP2・電池の穴 J1）、ボタン SW1〜SW3（左から 曲送り・音量＋・音量−） |
| 右の端（首の先のタブ） | 気圧センサー U3 とコンデンサ、JP3、線をつなぐ穴 J7。首には「CUT」の線 |

- 表と裏に **GND の大きな銅の面（ベタ）** を広げ、たくさんの小さな穴（ビア）で表と裏をつないだ。表の GND の端子は、すぐそばのビアで裏の面に落とした
- 電源の線は 0.4mm、スピーカーの線は 0.3mm、ほかの信号は 0.2mm の太さ
- 端子の名前は、裏に印刷した（どの穴が何か、裏から見て分かる）

## 部品ごとの中身

### 気圧センサー：DPS368（JLCPCB の部品番号 C3232508）

- I2C で使う（CSB を 3V3 につなぐ）
- SDO は何もつながない＝アドレス 0x77（DPS368 の中にプルアップがある）。はんだのジャンパー JP3 をつなぐと 0x76
- 電源の端子（VDD・VDDIO）のすぐそばに 0.1µF のコンデンサを1つずつ（データシートの接続例どおり）
- 端子の大きさはデータシートの推奨（0.35mm 角、0.65mm 間隔）で、自分で型を作った（KiCad にあった似た型とは寸法が少し違ったため）
- **センサーは基板のはみ出し部分（タブ）に載せる**。タブは本体と細い首（幅約5mm）でつながっていて、首を息の部屋の壁に通してふさぐと、センサーだけを息の部屋に入れられる
- 首を切り離したときは、タブの J7 と本体側の J5 を **4本の線**（3V3・GND・SDA・SCL）でつなぐ。息の部屋の作りに合わせて、センサーの位置を変えられる

### アンプ：MAX98357A（C910544）

- データシートの接続例どおり：電源のそばに 10µF と 0.1µF のコンデンサ（10µF は余裕をみて2つ）。裏の大きな端子（EP）は GND につなぐ
- SD_MODE（オン・オフ）は D7 から 4.7kΩ を通してつなぐ。データシートに「アンプの電源の電圧が、SD_MODE を動かす電圧（3.3V）より低くなる場合は、約2kΩ の抵抗を間に入れる」とあり、電池が減るとそうなるため
- 音量（GAIN）：何もつながない＝9dB（ふだんの音量はプログラムで変える）
- GAIN と SD_MODE は J4 の穴にも出してある。あとで変えたいときは、穴に抵抗を付ける
  - GAIN：GND へ 100kΩ＝15dB、GND へ直接＝12dB、VIN へ直接＝6dB、VIN へ 100kΩ＝3dB
  - D7 を使わずにアンプを常にオンにしたいときは、SD と 3V3 の間に 47kΩ
  - はじめは予備の抵抗の場所（R4〜R6）も作っていたが、基板が混み合うので外し、J4 の穴で代わりにした
- スピーカーの線は J3 へ

### 電源

- **電池（J1）→ Q1（逆接続の保護）→ JP2（電源スイッチの代わり）→ VBAT → XIAO の裏の BAT+**
  - Q1：電池の＋と−を逆につないでも、電気が流れないようにする。正しくつなげば、充電の向きにも流れる。Q1 が動かないときは JP1 をつなぐ
  - J1 は 2.0mm 間隔の穴（PH コネクタと同じ間隔）。電池の線を直接はんだ付けしても、PH のコネクタを付けてもよい。裏に BAT+・BAT− と印刷してある
- **XIAO の裏の BAT+ は、基板の窓から線でつなぐ**。XIAO を基板に直接はんだ付けすると、裏の端子に手が届かないため、基板の BAT+ の真下に窓（約3.2 × 3.7mm の穴）をあける。窓の横の TP1（基板の裏の端子）から、短い線で XIAO の BAT+ につなぐ
- **アンプの電源は「USB の 5V」と「電池」の高い方から自動で取る**（D1・D2）
  - USB だけ（電池なし）でも試せる。USB を抜くと、自動で電池から取る
  - はじめは、はんだのジャンパーで電源を選ぶ形にしていたが、2つ同時につなぐと 5V が電池に流れて危ないので、ダイオードの形に変えた
  - D1 は、もれる電気が少ない普通のダイオード（M7）にした。ショットキーダイオードにすると、電池だけのときに XIAO の 5V の線にもれた電気がたまり、XIAO の電池の切り替えを邪魔するおそれがあるため
- **電源スイッチは付けない**。使わないときは、プログラムで XIAO を深い眠り（ボタンで起きる）にする。どうしてもスイッチが要るときは、JP2 を切って J2 にスイッチをつなぐ

## 失敗に備えた工夫

| 心配なこと | 工夫 |
|---|---|
| DPS368 が動かない（向き・はんだの不良） | タブの首を切り離して、本体側の J5 に、手元の KIT_DPS368_2GO や DPS310 の基板を4本の線でつなぐ（切り離せば、壊れたセンサーが I2C の邪魔をしない） |
| MAX98357A が動かない | J4 に、**外付けのアンプ基板（Adafruit と同じ並び：LRC・BCLK・DIN・GAIN・SD・GND・VIN）**をつなぐ |
| アンプが全部だめ | J6 の D3 に**圧電ブザー**をつないで、直接鳴らす |
| ボタンが合わない | J6 に、**普通のタクトスイッチを線で**つなぐ（基板のボタンと同じ働き） |
| XIAO の付け方の失敗 | 縁の端子で直接はんだ付けする形と、**ピンヘッダで付ける（取り外せる）形**の両方に対応する |
| XIAO の裏の電池の端子に届かない | 基板の窓から線でつなぐ（ピンヘッダで付けた場合も同じ） |
| 電池の＋と−を逆につないだ | Q1 が電気を止める |
| 電池をつなぐ前に試したい | USB だけで、アンプまで動く（D1） |
| ピンの割り当ての間違い | プログラムでピンを変えられる。予備のピン（D6）も J6 に出す |
| 原因が分からない | J4・J5・J2 の穴と、TP2（5V）で電圧や信号を測れる |
| 部品の向きの間違い | 部品の名前・向き・1番ピンの印を、基板に**印刷**する |
| 部品の在庫切れ | JLCPCB の在庫が多い部品を選んだ（拡張部品は DPS368 と MAX98357A の2つだけ） |

## 組み立ての順番（基板が届いたら）

B版は XIAO が付いて届くので、1〜3 は要らない（USB をつないでプログラムを書き込み、4・5 だけ行う）。A版は次の順番。

1. 電池をつながずに、XIAO を基板に載せて、縁の端子を14か所はんだ付けする（USB の向きに注意。基板の「USB」の印刷の側）
2. USB をつないで、プログラムを書き込み、ボタン・音・気圧センサーが動くか確かめる（電池なしでも、USB の 5V でアンプまで動く）
3. 基板の裏の窓から、TP1 と XIAO の裏の BAT+ を短い線でつなぐ
4. 電池の線を J1 に付ける（**＋と−は裏の印刷を見る**。逆につないでも Q1 が守るが、つながない）
5. スピーカーの線を J3 に付ける
