## 全体の形

外径 26 mm・内径 23 mm の筒。吹き口の側から順に、次のように並ぶ。

| 順番 | 部分 | 中身 |
|---|---|---|
| 1 | 吹き口アダプター（D） | 短いストローを差す。差して回すと「カチッ」と固定される |
| 2 | 前の部屋（C） | 気圧センサーの載った基板のタブが入る。三角の窓と回すリング（E）が排気の出口 |
| 3 | 仕切り | C の後ろの壁。基板の細い首を通す切り込みと、通り道の小さな穴 |
| 4 | 後ろの部屋（A・B） | 基板（XIAO・アンプ）、その下に電池とスピーカー、壁に振動モーター、上に外付けボタン |
| 5 | 後ろのキャップ（F） | 半透明。XIAO の LED が透けて光る。端面に USB-C の口と、その蓋（G） |

- 胴体（A・B）は、**基板の面で縦に真っ二つに割る**（上の殻と下の殻）。基板のふちを上下の殻の溝ではさむ。左右に割ると、上のボタンが合わせ目に重なるため
- 息を測る前の部屋（C）だけは、**割らない一体の部品**にする（合わせ目から空気がもれないように）

## 3D プリンターで作る部品

| 記号 | 部品 | 材料 | 印刷の向き・設定 |
|---|---|---|---|
| A | 上の殻（ボタン付き） | PETG | 合わせ面を下にして寝かせる。サポートはボタンの穴まわりだけ |
| B | 下の殻（基板の溝・スピーカーの穴） | PETG | 合わせ面を下にして寝かせる。溝の幅 1.1 mm は試し刷りで合わせる |
| C | 前の部屋（仕切り・バヨネットの受け・三角の窓） | PETG | 吹き口側を上にして立てる。壁の線3本以上・中100% |
| D | 吹き口アダプター（ストロー側と本体側の2つに分かれ、間にフィルターをはさむ） | PETG | 立てて印刷。ストローの太さ違いで何個か |
| E | 回すリング（重さの調節） | PETG | 立てて印刷。内径は C の外径＋0.3 mm。内側に「カチッ」と止まる小さな突起 |
| F | 後ろのキャップ（光る） | 半透明 PETG | 端面を下にして立てる |
| G | USB の蓋 | TPU（やわらかい） | ひもで F につながった形にすると、なくさない |

はめ合わせる所のすき間は 0.2〜0.3 mm。バヨネットと基板の溝は、全部を印刷する前に小さく試し刷りする。

## 組み立ての順番

1. **下の殻に、電池・スピーカー・振動モーターを入れる**：B のくぼみに置いて両面テープでとめる。電池とスピーカーの線は、先に基板へはんだ付けしておく
2. **基板を下の殻の溝に置く**：気圧センサーのあるタブを、吹き口の側（前）に向ける
3. **前の部屋を、基板のタブにかぶせる**：仕切りの切り込みに基板の首を通し、すき間をグルーでふさぐ（通り道の穴はふさがない）。C のつば（フランジ）を B の溝にのせる
4. **上の殻をかぶせて、ねじでとめる**：A のボタンの線を J6 にはんだ付けしてから閉じる。C のつばが上下の溝にはさまって固定される
5. **後ろのキャップと USB の蓋を付ける**
6. **回すリングをはめる**：E を C の前からはめて、三角の窓の上まで送る
7. **吹き口を差して、回して固定する**：D の2つの部品の間にフィルター（金網＋スポンジ）をはさんでねじ込む。D の突起を C の溝に合わせて差し、90° 回すと「カチッ」と止まる。最後にストローを差す

## 空気のもれを抑える仕組み

| 部分 | 考え方 |
|---|---|
| 前の部屋 | 吹き口・気圧センサー・排気の出口がある部屋。割らない一体の部品なので、合わせ目からはもれない |
| 仕切り | 基板の首を通す切り込みのすき間をグルーでふさぎ、**φ0.6 mm の「通り道の穴」だけを残す** |
| 後ろの部屋 | ボタンの穴や殻の合わせ目からもれても、前の部屋とつながっているのは通り道の穴だけ |
| 出口 | 息のほとんどは、回すリングの切れ目と三角の窓が重なった所から出る。「ふつう」の位置で出口は約 1 mm²、通り道の穴は約 0.28 mm² |

- 通り道の穴を残す理由：完全にふさぐと、首のまわりのグルーが少しはがれただけで値が変わる。最初から決まった大きさの穴を残すと、もれ方が毎回同じになる
- 圧が足りなければ、通り道の穴をグルーでふさいで、完全に分ける
- USB の口は、使うときは蓋（G）でふさぐ
- 前の部屋は約 10 mL と小さい。圧は排気の出口の大きさと息の勢いで決まるので、部屋が小さくても吹けなくなることはない（小さいほうが反応が速く、吸う向きで使うときに吸い戻す息も少ない）。ストローからの息が気圧センサーに直接当たって値がばたつくときは、間に小さなじゃま板を入れる（吹いて確かめる）

## フィルター（吹き口アダプター D の中）

吐くだけでなく、**吸う向きでも使う**ため（例：ゆっくり吸う → 長く吐く）、吹き口にフィルターを入れる。

吸うとき、空気は「回すリングの窓 → 前の部屋（C）→ 吹き口アダプター（D）→ ストロー → 口」の順に通る。フィルターは、本体側の窓ではなく **D の中**に置く。

| | D の中（こちらにする） | 本体側の窓 |
|---|---|---|
| 筒の中のくず・ほこり | 止められる（口に入る直前なので、全部の空気が通る） | 止められない（窓より内側でできたくずは素通り） |
| 吐いた息の湿気・唾 | 気圧センサーに届く前に止められる | 止められない |
| 取りかえ・洗う | ストローと一緒に抜いて、D を開けて取り出せる | 本体を開けるか、リングを外す必要がある |

D の中だと、**吸うときは肺を守り、吐くときはセンサーを守る**の両方ができる。

### 中身：洗えるものを2枚重ねる

| 層 | 材料 | 役目 |
|---|---|---|
| 本体側 | ステンレス金網 #60〜#100（目の間隔 約0.25mm〜） | プラスチックのくずを止める。形を保つ |
| ストロー側 | 洗えるウレタンのスポンジ（ウレタンマスクを丸く切ったものなど） | 唾・湿気を受け止める |

- 1人で使う道具なので、細菌まで止める使い捨てフィルターではなく、**洗えるもの**にする
- 金網はモノタロウやミスミで「ステンレス金網」として、目の細かさ別に売っている。ホームセンターの金網は 16 メッシュなど目の粗いものが多く、フィルターには粗すぎる
- 金網は金切りばさみで丸く切る。切り口がほつれるので、D の2つの部品でふちをはさんで固定する
- D は「ストロー側」と「本体側」の2つに分け、ねじ込みで合わせる。間に金網とスポンジをはさむ

### 気をつけること

- **完全に乾かしてから使う**：湿ったままだとカビの原因になる。替えを2組用意して、交互に乾かす
- **濡れると重くなる**：スポンジが湿ると息が通りにくくなり、吹いたときの重さが変わる。どれくらい変わるかは、作って確かめる
- **何人も使うとき**（発表会場など）：人ごとにストローとフィルターを替える。使い捨ての細菌フィルター（肺活量の検査で使うもの）を使うほうが安心

## 回すリングで重さを変える（部品 C の窓と部品 E）

C の筒に三角形の窓をあけ、細い切れ目のあるリング E をかぶせる。切れ目と窓が重なった所だけが空気の出口になり、リングを回すほど出口が細くなって「重く」なる（ガスコンロのつまみと同じ考え方）。吸う向きで使う場合も、そのまま使える。

| 項目 | 寸法（仮） |
|---|---|
| 三角の窓 | 筒の上から回る向きに 0〜150°。長さ方向の幅が 3 mm → 0 に細くなる |
| リング E | 内径 26.3 mm・厚さ 1.5 mm・幅 6 mm |
| リングの切れ目 | 幅 0.8 mm（長さ方向に通す） |
| 段階 | 8段階（いちばん軽い〜閉じる）。150° ÷ 7 ≒ 21° ごと |
| 出口の広さ | 2.4 mm²（φ1.75 の穴と同じ広さ）〜 0。「窓の幅 × 切れ目の幅」で近似 |

作り方のこつ：

- **カチッと止める**：リングの内側に小さな突起（高さ 0.3 mm）を1つ、C の外側に浅いくぼみを 21° ごとに8つ
- **抜け止め**：リングの前後に、C の外側へ高さ 0.5 mm の段。リングは C の前から押し込んで、段を乗り越えさせる
- **リングのすき間からのもれ**：重さが足りなければ、すき間を詰めるか、リングの内側にシリコングリスを薄く塗る
- **窓の印刷**：C を立てて印刷すると、窓の細い先が層の段差でつぶれやすい。少し大きめに作り、細い先はやすりで整える
- **目盛り**：C の外側に8本の線、リングに矢印
- **先に試す**：C 全体を印刷する前に、窓の部分だけの短い筒とリングを刷って、重さと「カチッ」を確かめる

ほかに検討した案（[3案の比べ](https://claude.ai/artifact/SMZYKFVbkVCUaadgP71duA)）：

| 案 | 仕組み | 見送った理由 |
|---|---|---|
| 穴のダイヤル | 大きさの違う穴（φ0.6〜1.6 mm）を並べた円盤を回して選ぶ | 段階でしか変えられない（毎回同じ重さに戻せる長所はある） |
| ニードル弁 | とがったピンをねじで円すい形の穴に出し入れする | ピンの先の精度が要り、小さいねじは印刷しにくい |

## 決めること

- 筒の太さ（今は外径 26 mm）と、基板の幅 20.5 mm・電池・スピーカーが本当に収まるか
- ストローの太さ（アダプターの穴は今 φ6.2 mm）
- スピーカーの向き（下向きだと机に置いたとき音がこもる。φ15 mm なら横向きにもできる）
- 殻のとめ方（M2 ねじ＋埋め込みナット、またはツメ）
- 吹いて、通り道の穴（φ0.6 mm）と窓の大きさで、圧が十分に上がるか
- フィルターの金網の細かさ（#60〜#100）とスポンジの厚さ。重くなりすぎないか、吸う・吐くの両方で試す
