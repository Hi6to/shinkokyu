# 展示用の模型：紙パック風（案18）・タンブラー（案19）（11/11）

Award Day の **展示（expo）だけで使う模型**。発表のデモには使わない（デモは今の本体のまま）。
作るのは Hi6to さん（と Hi6to さんの Claude）。このファイルは、作る人がそのまま作業を始められるように、決まっていること・決めてほしいこと・確かめることをまとめたもの。

## なぜ作るか（アンケートの結果から）

事前アンケート（60件、docs/SURVEY_RESULTS.md）で、いちばん大きな壁は**くわえることへの抵抗**だった。

- 問17 で抵抗が「少しある・とてもある」が **40人（67%）**
- 理由（問18、53人）：人前でくわえるのが恥ずかしい 31、**電子たばこに見えそう 21**、周りに説明するのが面倒 21、音が出るのが気になる 19、衛生が気になる 18。記入には「サイズが大きい、煙がでるのであればタバコと思われそう」「単純にかっこ悪い」「見た目がちょっと…」

そこで、**くわえて吹いていても「飲み物を飲んでいる」ようにしか見えない形**を2つ、展示で見せる。「アンケートで 67% が抵抗ありと答えたので、こう変えられる」と話す材料にする。

## 2つの案

### 案18 紙パック風（`an18_carton`）

**ねらい**：平成に流行った、リプトンの紙パック（500 ml くらい）にストローを差して飲む感じ。机で紙パックの飲み物を飲むのは自然なので、まわりに説明しなくていい。

| 決まっていること | 中身 |
|---|---|
| 形 | 紙パックの飲み物だと一目でわかる形。**ただの直方体の箱はだめ**（電子たばこに見える） |
| 紙パックらしさ | 上の折り目・つなぎ目のヒレ・ストローの差し口・ストローが斜めに刺さっている、など。どれを入れるかは作る人が決める |
| ストロー | 上から斜めに出す。本物の本体と同じ **φ6 のストロー**が差せるとよい（`adapter_parts.py` の⑥と同じ太さ） |
| ロゴ・商品名 | **本物の商品のロゴ・名前・柄は入れない**（リプトンなど）。入れるなら「シン呼吸」など自分たちの文字だけ |

**形と大きさ（11/11：写真から決めた）**

参考にしたもの：市販の紙パック飲料（450 ml）。形だけを参考にした（商品写真は権利の都合でリポジトリに置かない）

- 形は **屋根型（ゲーブルトップ）**：四角い胴 → 前後2枚の斜めの屋根 → てっぺんに薄いヒレ（貼り合わせの部分）。横から見ると、屋根の両端が三角になる
- 写真の画素から測った比（正面の幅を 1 とする。写真は斜め上から見ているので、屋根は少し低く見えている）

| 所 | 写真の画素 | 比 | 決めた寸法（W = 72） |
|---|---|---|---|
| 正面の幅 W | 185 | 1 | **72** |
| 奥行き D | （横の面は斜めで細く見える。断面は正方形とみなす） | 1 | **72** |
| 胴の高さ（縦の壁） | 282 | 1.52 | **110** |
| 屋根（肩からヒレの下まで、見えている高さ） | 51 | 0.28 | **22**（見た目で 20〜26 の間で直してよい） |
| ヒレ | 32 | 0.17 | **12**（厚さ 2） |
| 全体の高さ | 365 | 1.97 | **約 144** |

- W = 72 にした理由：中に今の本体（案1：外径 26、全長 約 113）を**立てて**入れられる高さ（胴＋屋根の中で約 125）がとれるから。ゆったり版（外径 32）も入る。基板（20.5 × 69.3）・XIAO 2枚・スピーカー・電池だけなら、もっと余裕がある
- 壁の厚さは 2。台（Ender-3 は 220 × 220、高さ 250）にも S3 にも乗る
- ストローの差し口：屋根の、写真の「あけぐち」がある側の斜めの面に、φ6.5 の穴。ストローは**その側へ少し傾けて**（15〜20°）出す
- 中に本体を入れるか、中は空の模型にするかは、下の「本体を入れるか」

### 案19 タンブラー（`an19_tumbler`）

**ねらい**：ストローつきのふたのタンブラーの中に、本体を隠す。外から見ると、ふつうのタンブラーで飲み物を飲んでいるだけ。

| 決まっていること | 中身 |
|---|---|
| 形 | ふたつきのタンブラー。ふたの穴からストローが出ていて、そこから吹く |
| 本体の隠し方 | 本体はタンブラーの中。外からは見えない |
| ストロー | ふたの穴から φ6 のストロー。中で本体の吹き口につながる形にするか、見た目だけにするかは作る人が決める |
| ロゴ・柄 | 本物の商品（スターバックスなど）に似せない。無地か「シン呼吸」の文字だけ |

**形と大きさ（11/11：写真から決めた）**

参考にしたもの：市販のストローつきのふたのタンブラー。形だけを参考にした（商品写真は権利の都合でリポジトリに置かない）

- 形：**上が広く下がすぼまる**筒（円すい台）。ふたは平らで、ふちが少し外へ出る。ふたの上に、ストローの口と、小さなつまみ（飲み口のふた）がある
- 写真の画素から測った比（上の直径を 1 とする。オレンジと青緑の2つの平均）

| 所 | 写真の画素（オレンジ／青緑） | 比 | 決めた寸法（D = 70） |
|---|---|---|---|
| 上の直径（ふた） | 44 ／ 48 | 1 | **70** |
| 下の直径 | 31 ／ 35 | 0.72 | **50** |
| 高さ（底からふたの上まで） | 83 ／ 92 | 1.9 | **133** |
| ふたの厚さ | 約 6 | 0.13 | **9** |
| つまみ（ふたの上） | 約 10 | 0.2 | 高さ **14**・直径 **14** |
| ストロー（ふたから上に出る長さ、左の白いもの） | — | 約 0.35 | **25**。中心から **20** ずらした所 |

- D = 70 にした理由：底の内側の直径が約 46、ふたの下までの高さが約 122 とれるので、今の本体（案1：外径 26、全長 約 113）を**立てて**入れられる。ゆったり版（外径 32）も入る
- 壁の厚さは 2。台にも乗る
- 本体を入れて本当に吹けるようにするなら：ストローの位置（中心から 20）と、本体の吹き口の位置（底では中心から 10 までしかずらせない）が合わないので、**ストローを中心寄り（10 以内）に動かすか、本体を少し傾けて立てる**。中が空の模型なら、写真どおり 20 でよい
- ふたの開け方（はめこむ／ねじる）は作る人が決める

## 2つに共通すること

| 項目 | 中身 |
|---|---|
| 使う場面 | **展示だけ**。机に置いて見せる・手に取ってもらう。発表のデモには使わない |
| LED が見えるか | 呼吸を促すのは**本体の LED の色の変化**が基本（11/09 に決めた）。本体を中に入れる場合は、使う人から LED が見える**窓**を作る（ABS グレーだけで刷るなら、穴か、薄くして光が透ける所）。本体の LED の位置は TASKS.md の L01 で決まる。中が空の模型なら、窓の場所だけ形で示せばよい |
| 避けること | ただの直方体・細い棒の形（電子たばこに見える）。火や煙をイメージさせる飾り |
| 材料 | 手元の UltiMaker S3 は **ABS グレーだけ**（[ultimaker_abs/README.md](ultimaker_abs/README.md)）。色は刷ったあとにシールや塗装でつけてよい（展示用なので） |
| 台の大きさ | Ender-3 V3 SE：220 × 220、高さ 250。S3 で刷るなら S3 の大きさに合わせる。高い部品は分けて刷り、あとで貼ってよい |
| 時間 | 11/14 の通し練習までに、少なくとも1つは刷り上がっていること。2つとも間に合わなければ、**案18 を先に**（紙パックの方が「飲み物」と一目でわかりやすい） |

### 本体を入れるか（作る人が決める）

| やり方 | よいところ | 気をつけること |
|---|---|---|
| A. 中は空の模型（見た目だけ） | 早い。寸法の制約が少ない | 吹いても何も起きない。展示では「見た目の提案」として見せる |
| B. 今の本体（案1）を入れる | 吹くと本当に LED が変わる。展示で体験してもらえる | 本体の出し入れ・USB で充電する口・ストローと吹き口のつなぎを考える必要がある。時間がかかる |

おすすめは、**まず A で両方の形を作り、余裕があれば案19（タンブラー）だけ B にする**。タンブラーは筒の中に本体を立てて入れるだけなので、B にしやすい。

## 作り方（今のデータの決まりにそろえる）

スクリプトの上に置く定数（このまま使ってよい）：

```python
# 案18 紙パック風（carton_parts.py）
CARTON_W = 72.0        # 正面の幅（= 奥行き。断面は正方形）
CARTON_WALL_H = 110.0  # 胴の高さ（縦の壁）
CARTON_ROOF_H = 22.0   # 肩からヒレの下まで
CARTON_FIN_H = 12.0    # てっぺんのヒレ
CARTON_FIN_T = 2.0     # ヒレの厚さ
CARTON_T = 2.0         # 壁の厚さ
STRAW_HOLE_D = 6.5     # ストロー φ6 が通る穴
STRAW_TILT_DEG = 18.0  # ストローの傾き（あけぐちの側へ）

# 案19 タンブラー（tumbler_parts.py）
TUMBLER_TOP_D = 70.0   # 上の直径（ふた）
TUMBLER_BOT_D = 50.0   # 下の直径
TUMBLER_H = 133.0      # 底からふたの上まで
TUMBLER_LID_T = 9.0    # ふたの厚さ
TUMBLER_KNOB = (14.0, 14.0)  # つまみの直径・高さ
TUMBLER_STRAW_OFF = 20.0     # ストローの中心からのずれ（本体を入れて吹けるようにするなら 10 以内）
TUMBLER_STRAW_UP = 25.0      # ストローがふたから出る長さ
TUMBLER_T = 2.0        # 壁の厚さ

# 中に入れるもの（本体を入れる場合の確かめ用。body_parts.py・body_wide.py と同じ値）
BODY_D, BODY_L = 26.0, 113.0      # 今の案1（ゆったり版は 32）
BOARD = (20.5, 69.3, 0.8)          # B版の基板
```

- 部品のスクリプトは `hardware/print/` に置く：案18 は `carton_parts.py`、案19 は `tumbler_parts.py`（ほかの案と同じく `manifold3d` で書く。`bottle_parts.py`・`body_wide.py` が手本）
- 寸法はファイルの上に定数でまとめる（実物を測ったら、そこだけ直せばよいように）
- `check()` で確かめる：部品がそれぞれ1つにつながっているか／台に乗るか／（B にするなら）本体が中でぶつからないか、出し入れできるか、ストロー φ6 が通るか
- 刷るデータは `ultimaker_abs/an18_carton/`・`ultimaker_abs/an19_tumbler/` に、ほかの案と同じく `README.md`（刷る順番・向き・時間・量）と `.ufp` を置く
- このファイルの下の「結果」に、刷った写真（`docs/images/`）と、実際の大きさ・時間を書き足す
- [docs/shapes.html](../../docs/shapes.html) に案18・案19 を足すかは任せる
