# UltiMaker S3・ABS グレーだけで作る（11/07）

手元の UltiMaker S3 で使える材料が **ABS グレーだけ**なので、PETG・TPU・光造形を使わずに、すべての部品を ABS で作れるようにした版。
形の元は oira0822 さんのデータ（[../README.md](../README.md)）と同じ。変えたのは、TPU の部品の代わりと、ABS できれいに刷るための所だけ（下の「直したところ」）。

> **11/08：吹き口アダプターを直した**（ストローを実物の外径 6mm に合わせ、⑥ のつかみを強くした）。`ufp/abs_adapter_set.ufp` は古いので、Cura で `plates/abs_adapter_set.stl` から作り直す。刷り直すのは **②・⑤・⑥ だけ**（④ は変わっていない）。

> **11/08：ペットボトル形（`an01b_tube_bottle`）を足した。** 板は `plates/abs_bottle_C.stl`（前の部屋 C）と `plates/abs_bottle_adapter.stl`（肩 ②・キャップ ⑤・つかみ ⑥）。殻 A・B と小物は今の案1 と同じ板。.ufp は Cura で作る。あわせて ④ の「カチッ」の山がカップの内側へ 0.5 出て ② の胴に当たっていたのを直した（今の形で ④ を刷り直すときは新しい STL を使う）。

## FFF で形がくずれにくくする設計の決まり（11/08）

FFF（溶かした樹脂を積む方式）の設計の手引きを調べて、よく挙がる決まりを全部の部品に当てはめた。数字は手引きの目安で、プリンターと材料で変わる。

| 決まり | 目安 | ここでしたこと |
|---|---|---|
| 張り出し | 45° まで（それより寝ると支えが要る） | 殻の内側は 45° の屋根。B の輪の下は 45° の V（11/07） |
| 橋（空中に渡す線） | 5mm より短いと、たれが目立たない | 殻・コアの天井の下に、抜く支えを形に入れ、4.4mm 以下に分けた（11/07） |
| 壁の厚さ | 線2本（0.8mm）以上。強さが要る所は 1.2〜2mm | 全部品の断面を調べた。直したのは支えの両はしの壁だけ（0.4 → 0.8mm）。B・A の前の溝の所は 0.9mm（oira0822 さんの形のまま） |
| 台にふれるふち | **45° の面取りか丸め**。1層目が押しつぶされて外へ広がる「象の足」で、はめ合いがきつくなるのを防ぐ | **全部品の、台にふれるふちを 45° で面取り**（大きい部品 0.4mm・小さい部品 0.3mm）。穴のふちも広がるので、1層目で穴が小さくなるのも防ぐ。殻 A・B の合わせ目は、外から細い V の溝に見える（合わせ目のずれが目立たない） |
| 横向きの穴 | 上をとがらせる（しずく形）。丸い穴の上は、たれる | マッチの外箱の押し棒の穴3つ（しずく形）と円盤の窓（先を幅 4mm で平らに）、コアの前の息の穴（しずく形） |
| 角 | 丸める。とがった角に縮む力が集まり、反って浮く | 箱のコア・社員証の枠・マッチの外箱と内箱（11/07） |
| 細い棒（直径 5mm 未満） | 折れやすい。根元に丸みをつける | 押し棒（直径 3.7）の根元を、つばの上 0.5mm だけ 45° で太らせた（穴には入らない高さ）。断面を回して1つの形で作った |
| 小さい穴 | 小さめに刷れる。大事な寸法は、あとでドリル | C の通り道の穴（φ0.6。わざと決まった量だけ息をもらす穴）は、ふさがりやすい。両面にすり鉢をつけた。ふさがっていたら **φ0.6 のドリル（ピンバイス）で開ける** |
| すき間 | 動く所は片側 0.2〜0.3mm が目安 | 今の形のまま（リング E と C は 0.15。きついときは、やすりで整える） |

- 形を作る関数：`make_print.py` の `bed_chamfer()`・`teardrop_y()`・`plunger_abs()`、`body_parts.py` の `breakaway()`
- この PC の manifold3d 3.5.4（Windows）は、平面で切る計算（`trim_by_plane`）がくずれ、同じ位置の面が重なる足し算・引き算でも面が残る。面取りはこれを使わない作り方にし、作った STL がすべて閉じた形（すき間のない形）になっているのを確かめた
- 調べた元：[Hubs：FDM の部品の設計](https://www.hubs.com/knowledge-base/how-design-parts-fdm-3d-printing/)（張り出し 45°・橋 5mm・台のふちの面取り・細い棒）、[Makerverse：FDM の設計の手引き](https://www.makerverse.com/resources/the-fused-deposition-modeling-fdm-design-guide/)、[メルボルン大学 FabLab：FDM のための形の作り方](https://ms-kb.msd.unimelb.edu.au/the-fablab/3d-printing/fdm/modelling-for-fdm)、[33d.ch：FDM の設計の決まり](https://www.33d.ch/en/blog/3d-printing-design-rules-for-beginners-fdm-basic-c)（壁の厚さ）、[Markforged：反り](https://markforged.com/blog/3d-printed-part-warping)・[メルボルン大学：反りを防ぐ](https://ms-kb.msd.unimelb.edu.au/next-lab/3d-printing/key-techniques/warping)（角の丸め）、[Sovol：FDM のすき間](https://www.sovol3d.com/blogs/news/fdm-3d-printing-tolerances-clearances-how-to-design-parts-that-fit)（動く所のすき間）

## 11/07 の試し刷りを受けて直したところ

**起きたこと**：`abs_body_tube`（11/07 の、筒の部品をまとめた板。直す前）を刷ると、下の殻 B の内側の真ん中が、糸がからまったように崩れた。外の面にも、その上をなぞった筋が出た。

**わけ**：殻は合わせ面を下にして刷るので、内側の一番奥（45° の屋根の先）が、**幅 8.9 × 長さ 64mm の、支えのない平らな天井（橋）**になる。ABS は冷やす風を弱くする（最大 15%）ので、空中に渡した線がたれて崩れやすい。そこへスピーカーの輪（天井からぶら下がる円の弧）と音の穴がかかって、さらに崩れた。同じ形の天井は、上の殻 A（押し棒の穴つき）と、箱のコアの上の殻（**幅 21mm**）にもあった。

表の数字は、支えのない天井の点から、すぐ下の壁や支えまでの一番長いきょり（空中に渡す線の長さの半分くらい）。

| 部品 | 直したこと | 支えまでの一番長いきょり |
|---|---|---|
| A 上の殻・B 下の殻 | 天井の下に、**あとで抜く支えの壁**（2本。天井と 0.25 のすき間） | 4.8 → 1.8 mm |
| B 下の殻 | スピーカーの輪の、下の部分（円の弧）を 45° の V に。スピーカーにふれる高さは変えない | 弧が宙に浮かない |
| C 前の部屋 | **つば（仕切りの壁）を下にして刷る**。首と本体の境の外の角を 0.8 面取り（首の上に本体が張り出すため） | 9.7 → 1.3 mm（仕切りが台の上で、すき間なく平らにできる） |
| 箱のコアの上の殻（案7・15・17） | 天井の下に、あとで抜く支えの格子 | 10.6 → 1.7 mm |
| ゆったり版の A・B・C | 同じ（支えの壁・C はつばを下） | 6.0 → 2.1 mm、10.8 → 1.8 mm |

- 断面の図：[section_1107.svg](section_1107.svg)（直す前と後。橙が支え）
- **支えの抜き方**：台が冷えてから部品を外す。支えは殻の内側（開いている側）に立っていて、殻とは 0.25 離れているので、ペンチやピンセットでつまんで引けば抜ける（台に残ることもある）。天井の内側に少し筋が残るが、外からは見えない
- 支えは形（STL）に入れてある。**Cura のサポートはオフのまま**にする
- C の三角の窓のふちは、前と同じ（少しずつ張り出して閉じる形で、向きを変えても変わらない）
- C の首が筒から外れた別の部品になっていた件は、oira0822 さんが直した（df7c556。同じ直し方）。11/07 に刷った C は、首が弱いので刷り直す

## 案15（社員証）・案17（マッチ）の ABS 版で変えたところ

ABS は冷えると縮む力が強く、**大きく平らな部品や、角のとがった箱は、角から反って台から浮く**。形は oira0822 さんのもの（`../enclosure/shapes/stl/`）のまま、次だけ変えた（`make_print.py` の `shapes_abs()`）。

| 部品 | 変えたこと | なぜ |
|---|---|---|
| 箱のコア（下の殻・上の殻。案7 のひもの輪つきも） | 外の縦の角を半径 2 に丸める | 合わせ目が反ると、息がもれる |
| 社員証の裏の枠（96 × 88） | 外の角を半径 4 に。**カードの下の板に窓**（ふち 6mm を残す） | 一番大きく平らな部品。縮む板を減らす（体積 18.4 → 12.0 cm³）。カードは表と裏のふちではさまる |
| 社員証の表の枠 | 外のへりの2つの角を半径 4 に（コアの側は裏とそろえて四角） | 反り |
| マッチの外箱（立てて刷る） | 長い4本の角を半径 2.5 に | 反り・層の割れ |
| マッチの内箱 | 縦の角を半径 2 に | 反り。外箱にすべりこむ向きは変わらない |

- ABS は約 0.5% 縮む。カードの入る所の幅 54.6 は約 54.3 になる（カード 54.0 は入る）。コアと外箱は両方縮むので、すき間は変わらない
- 空気口の円盤（core_dial）の切れ目は 0.8 → 0 に細くなる形。FFF ではノズル（0.4）より細い所がふさがるので、開く広さの細かい段は出にくい。足りなければ、カッターで切れ目を少し広げる

## TPU の部品を ABS に変えたところ

| 部品 | 元（TPU） | ABS 版 | 形を作る関数 |
|---|---|---|---|
| G USB のふた | やわらかい栓をたわませて差す | **かたい栓に、つぶれる細い山（半径 0.3、0.3 はみ出す）を4つの面につけて押しこむ**。先は 0.4 の面取り | `body_parts.lid_G_abs()` |
| ⑥ ストローをつかむ筒 | やわらかい円すいの筒 | **割れ目入りのつかみ（コレット）**。ケーブルグランドの硬いつかみと同じで、⑤ をしめると4本の指が坂に押されて閉じ、ストローをつかむ。指の太さは 0.9〜1.7mm（FFF で刷れる太さ） | `adapter_parts.collet6_abs()` |
| ② ストロー側 | ⑥ が入る坂 | ⑥ のコレットに合わせて、坂を少し太くした（ねじまでの壁は 1.4mm 残る） | `adapter_parts.part2(abs_=True)` |

- ⑥ のつばを TPU 版より 1mm 高くした。⑤ の天井が早く当たり、そこから約 1.5mm しめこめる（指が半径で約 0.24mm 閉じる。ストローとのすき間は 0.1）
- ⑥ はストローとの間から少し息がもれるかもしれない。気になるときは、ストローに薄くテープを巻いて太らせる

## ABS で刷るときに気をつけること

| こと | 対策 |
|---|---|
| **反り**（角が浮く） | ガラスに**スティックのりを薄く塗る**（UltiMaker の指示）。ブリム 7mm は .ufp に入っている。台を 85℃ に温めきってから始まる |
| **層の割れ** | すき間風の当たらない所で刷る。扉があれば閉める。刷り終わっても、台が冷えるまで外さない |
| **におい** | 換気する。そばに長くいない |
| **ノズルの塊**（11/07 に起きた） | 最初の数層はそばで見る。はがれたら、すぐ「中止」。前回の塊を取ってから刷る |
| 縮み | ABS は冷えると少し縮む（約 0.5%）。はめ合い（リング E・ねじ・カチッ）がきついときは、やすりで整える |

## 口にふれる所

吹き口アダプター（②④⑤⑥）も ABS になる。口にふれるのは**市販のストローだけ**で、アダプターは口にふれない作り（元の設計と同じ）。アダプターは水で洗って乾かす（熱湯や食洗機は使わない）。

## 作り直し方

1. `hardware/print` で `python make_print.py --ultimaker-abs`（部品の STL と板の STL を作る）
   - shapes の STL（案3・5・7・15・17）は毎回 `../enclosure/shapes/stl/` から取りこむ。oira0822 さんが shapes を直したら、これを実行し直す
   - manifold3d 3.5.4（Windows）は形の計算の一部がくずれるため、この PC ではゆったり版（`body_wide.py`）を作り直せない。そのときは、コミットしてある `stl/wide_*.stl` を使う（表示が出る）
2. Cura でプリンターを UltiMaker S3 にし、1番の材料を **UltiMaker → ABS → Gray ABS**、ノズルを **AA 0.4** にする（2番は「Enabled」を外す）
3. `plates/` の板の STL を開き、表の設定にする（ふつう＝Normal 0.15mm・壁 4周（Wall Line Count 4）・中 20%。細かい＝Engineering の Fine 0.1mm・壁 4周・中 100%。どちらもブリムをオン、**サポートはオフ**）
4. スライスして「Save to Disk」で `.ufp` を `ufp/` に保存する
