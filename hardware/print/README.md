[docs/shapes.html](../../docs/shapes.html) に残した案（案1・3・5・7・15・17）を、キカイノイエのプリンターで刷るためのデータ。2通りある。

| フォルダ | 作り方 |
|---|---|
| [fff_only/](fff_only/) | **すべて FFF**（Creality Ender-3 V3 SE）で作る |
| [fff_resin/](fff_resin/) | ほとんど FFF。**細かい飾りと空気口の円盤だけ光造形**（ELEGOO Mars4 Ultra） |

## 案1 のペットボトル形（11/08）

今の案1 の先（細い首・④・② のつば・ねじ）をなくし、**本体 → 丸い肩 → 首 → キャップ** の自然な形にした版（[`bottle_parts.py`](bottle_parts.py)、案の名前 `an01b_tube_bottle`）。今の案1 のデータは残している。

| 部品 | 中身 |
|---|---|
| C 前の部屋 | 先がそのまま**カップ**（L 字の溝・フィルターの座）。**④ はいらない**（④ の差しこみを押しこむ所がなくなる） |
| ② 肩 | 下は φ26（C と同じ太さ）で、丸く細くなって首（ねじ）になる。肩を持って 55° 回すと「カチッ」 |
| ⑤ キャップ | φ20.6、ペットボトルのキャップのような縦のみぞ。ねじは中に隠れる |
| ⑥ つかみ・フィルター・ストロー φ6 | 11/08 に直した形と同じ |
| 殻 A・B、リング E、キャップ F、USB のふた G、押し棒 | 今のものをそのまま使う |

全長は約 108 mm（今の形は約 113 mm）。刷るのは **C と ②⑤⑥**。`python3 bottle_parts.py` で次を確かめる（`make_print.py` も書き出す前に確かめる）：部品が1つにつながっているか／② と C、⑤ と ② がぶつからないか／押しこんで「カチッ」を越えるときに肩が C に当たらないか／ストロー φ6 が通り、締めると半径で約 0.3 mm 食いこむか／C が殻 A・B・リング E にぶつからないか。

## 案1 のゆったり版（外径 32。11/07）

今の案1（外径 26）は残したまま、**中の部品に余裕を持たせた版**を別に作った（[`body_wide.py`](body_wide.py)）。UltiMaker 用の板は `ultimaker_abs/plates/abs_wide_*.stl`。

今の案1 の筒に、中に入る部品の外形を入れて比べた（部品の高さは仮の値：XIAO 1枚 5mm、スピーカーの厚さ 5mm。実物を測って `body_wide.py` の `XIAO_H`・`SPK_T` を直す）。

| 部品 | 今の案1（内側の半径 11.5） | ゆったり版（内側の半径 14.4） |
|---|---|---|
| 2枚目の XIAO（Sense）を1枚目に重ねる | **入らない**（上の角が軸から 14.0） | 入る（余裕 約 0.5） |
| スピーカー φ20（基板の棚の下） | **入らない**（下の角が軸から 12.3） | 入る（下の角まで余裕 約 2.2。上は棚の下 0.3） |
| 1枚目の XIAO | 入る（余裕 約 0.7） | 入る（余裕 約 0.9） |
| 電池 26×15×4 | 入る | 入る（余裕 約 2.3） |
| 基板の溝のすき間（片側） | 0.2 | 0.35（チームの試し刷りの箱と同じ） |

| 変えたこと | 中身 |
|---|---|
| 筒の太さ | 外径 26 → **32**（内径 23 → 28.8）。壁の厚さ 1.6 は同じ |
| 息の部屋（C の中） | 太さは今の案1 と同じ（半径 11.5）。息の判定のしきい値を変えずに済むように、C の壁を厚くした |
| 変えていないこと | 基板の位置・ボタンの位置と印・溝の位置・USB の口・吹き口の穴（φ10.2）。**吹き口アダプター（②④⑤⑥）と USB のふた G は今の案1 のものを使う** |
| クリップ・スタンド | 筒が太くなった分、クリップの輪とスタンドの穴（φ32.7）を合わせた。スタンドは、穴のまわり（火山の火口・炎の上・剣の岩の上・ロケットのひれ）だけ外へ広げた |

`body_wide.py` を実行すると（`python3 body_wide.py`）、次を確かめる。`make_print.py` も、書き出す前に同じ確かめをする。
1. 部品がそれぞれ1つにつながっているか（11/07 に C の仕切りが外れていたことの再発を防ぐ）
2. 中の部品（基板・XIAO 2枚・ボタン・スピーカー・電池）が殻にぶつからないか、内側までの余裕
3. 組み立てたとき、部品どうし（A・B・C・E・F）がぶつからないか
4. スタンドに筒がぶつからずに入り、棚にのるか

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `gcode/` | 板（1回の印刷）ごとの G-code。Ender-3 V3 SE 用。案どうしで同じ板は1つにまとめた |
| `plates/` | 板ごとに部品を並べた STL。**Ender 以外のプリンター（Bambu A1 など）で刷るときはこれ**を各プリンターのソフトに入れる |
| `stl/` | 部品ごとの STL（刷る向きに置いたもの） |
| `config/` | PrusaSlicer の設定（台・温度・速さ） |
| `body_parts.py` | 案1 の筒のうち、チームのデータにまだなかった部品（A・C・E・F・G・押し棒） |
| `adapter_parts.py` | 洗える吹き口アダプター（②④⑤⑥） |
| `make_print.py` | 上の全部を作り直す。SD カードに案ごとの G-code を番号つきでコピーもできる |
| `summary.json` | 部品の大きさ、板ごとの時間・量 |

作り直す（このフォルダで）：

```
python3 make_print.py                                   # STL・G-code・案ごとの README を作り直す
python3 make_print.py --sd fff_only an15_idcase <SDカードの場所>   # その案で刷る G-code だけを SD へ
```

必要なもの：Python の manifold3d・trimesh・numpy、PrusaSlicer 2.7（コマンドの `prusa-slicer`）。

## 刷る前に：実現できるかを確かめ直した結果

これまでに話したこと（基板の寸法、店のプリンター、洗えるアダプター、shapes.html の各案）と、データを作りながら確かめたこと。

### 確かめられたこと（データで確認）

| 項目 | 結果 |
|---|---|
| 台に乗るか | 全部の板が Ender-3 V3 SE の台（220 × 220、高さ 250）に乗る。いちばん高いのは案17 の外箱 77 mm |
| 形がこわれていないか | 全部の部品が「閉じた形」（watertight）。スライスでエラーなし |
| 支え（サポート） | 全部の部品をサポートなしで刷る向きに置いた（下の「向き」） |
| 光造形の台（153 × 77、高さ 165）に乗るか | 円盤 16 mm・発射塔 95 × 22.5・葉っぱ 44 × 12 は乗る。火山（φ80）と社員証の枠（88 mm）は乗らないので、光造形にしない |
| TPU | 店の説明では、TPU を使えるのは Ender-3 V3 SE と V3 KE だけ（Bambu A1 は PLA・PETG だけ）。TPU の板は Ender で刷る |

### 新しく作った部品（案1 の筒）

チームの `hardware/enclosure/make_enclosure.py` には **下の殻 B しかなかった**ので、同じ寸法・座標で残りを作った。

| 記号 | 部品 | 作り方・確かめたこと |
|---|---|---|
| A | 上の殻 | B の内側（45° の屋根）を上下にひっくり返した形。合わせ面を下にしてサポートなしで刷れる。ボタン3つの上に押し棒の穴と、ぐらつかないための筒（高さ 3） |
| C | 前の部屋 | 一体の筒。後ろのつばが仕切りの壁（基板のタブを通す 12.6 × 1.4 の穴と φ0.6 の通り道の穴）。前は 45° で細くなり、④ を差す穴 φ10.2。**吹き口の側を下にして立てて刷る**（張り出しなし） |
| E | 回すリング | 幅 8.2。**C を殻に差す前に、C の後ろからはめる**。殻の前の面とふち（φ27.6）の間に閉じこめられるので抜けない。8段階でカチッ |
| F | 後ろのキャップ | USB-C のケーブルの太い所が入る口（13.5 × 8.8）。口は真ん中より少し上にあるので、横長の向きを基板に合わせて差す |
| G | USB のふた | TPU。F の口に差す |
| ― | 殻のとめ方 | 後ろは F の差しこみ、前は C の首が上下の殻の内側に入るので、両端で上下の殻がはさまれる。真ん中がすくなら、テープか接着で仮止め（ねじにするかはチームで決める） |

### ボタンの印（11/07）

押し棒の穴の横に、ボタンの役目の印をつけた。並びは本体のプログラム（[firmware/shinkokyu](../../firmware/shinkokyu/)）の割り当てと同じ。

| ボタン | 役目 | 印 |
|---|---|---|
| SW1（X=30.4） | 曲送り（長押しで一服のお誘い） | ▶（吹き口の向きを指す） |
| SW2（X=38.2） | 音量を上げる | ＋ |
| SW3（X=46.0） | 音量を下げる | － |

| 部品 | つけ方 | 理由 |
|---|---|---|
| A 上の殻（案1・3・5） | 筒の面から **高さ 0.5 で浮き出し**（大きさ 4.4・線の太さ 1.0） | 殻の天井は平らで、穴の横（Y=−3.7）は壁が 0.66mm しかない。彫ると穴があく。浮き出しなら、指でさわっても分かる |
| core_front（案7・15・17 のコア） | 上の面に **深さ 0.6 で彫る** | 案17 ではコアが外箱にぴったり入るので、浮き出すとぶつかる |
| match_sleeve（案17 の外箱） | ボタンの穴の横の外の面に **深さ 0.6 で彫る** | 外箱に入れるとコアの印が見えないため |

- 振動モーターは一旦入れない（11/07）。
- STL・板の STL（`plates/`）・[docs/shapes.html](../../docs/shapes.html) の模型は新しくした。**G-code（`body_tube`・`core_case`・`core_case_match`・`necklace`・`match_sleeve`）は古いまま**。PrusaSlicer がある PC で `python3 make_print.py` を実行して作り直す（TASKS.md の J15）。

### 洗えるアダプター（②④⑤⑥）

| 部品 | 作り方 |
|---|---|
| ② ストロー側 | 後ろに突起2つ。前に丸いねじ（ピッチ 3）。中にストローが止まる段 |
| ④ 本体側 | 差しこみ φ10 × 6（本体の穴 φ10.2 に差す。O リング 内径8 × 太さ1 の溝つき、なくても使える）。カップの壁の中に L 字の溝（外からは見えない） |
| ② と ④ の固定 | ② を押しこんで **55° 回すとカチッ**。溝の天井の小さな山を乗り越えるとき、間の ③ のスポンジが縮んでばねになる |
| ⑤ しめる帽子 | ② のねじにしめると、中の ⑥ が坂に押しこまれてストローをつかむ（ケーブルグランドと同じ） |
| ⑥ やわらかい筒 | TPU。外が円すい |
| 材料・設定 | PETG、層 0.12 mm、**中まで 100%**（すき間に水が入って乾かないことを防ぐ）。口がふれるのは市販のストローだけ |

### まだ決まっていない・確かめが要ること

| 項目 | 内容 | どうするか |
|---|---|---|
| **ストローの太さ** | 外径をまだ測っていない。今は外径 8.0 mm で作った | 測って `adapter_parts.py` の `STRAW_OD` を変え、`python3 make_print.py` で作り直す |
| **ボタンの方式**（TASKS の T05・J01） | 基板のボタンを押し棒で押すか、外付けボタンにするか未定。A は「基板のボタンを押し棒で押す」形で作った | 外付けに決まったら、A の穴を外付けボタンに合わせて作り直す |
| **2枚目の XIAO**（TASKS の V05） | 筒の中のどこに入れるか未定。A・B には場所を作っていない | 決まったら A・B を直す |
| L 字の USB プラグ | 案5 の横から充電するスタンドで、F の口から L 字のプラグが入るか | プラグの寸法を測って、F の口と比べる |
| スピーカー | 筒の中で φ20 のスピーカーの入る幅がぎりぎり（B はチームの設計のまま） | B を刷って、実物を入れて確かめる |
| 細い切れ目 | FFF（ノズル 0.4 mm）では、0.3〜0.4 mm より細いすき間はつぶれる。C の三角の窓の先と、円盤の切れ目の先は、細い所が開かない | 段階が少し減るだけで使える。気になる円盤は光造形版にする。窓の先はやすりで整える |
| アダプターの突起 | ② の突起（1.4 mm）は、刷るとき少しだけ張り出す | ふつうは刷れる。だれたら、やすりで整える |
| A1 用の G-code | Bambu A1 の G-code はここでは正しく作れないため、作っていない | `plates/` の STL を Bambu Studio に入れて刷る |
| 光造形のデータ | 光造形の切り分け（.goo など）はここでは作れない | `fff_resin/…/resin/` の STL を店のソフトに入れる |

**まず試し刷り**：全部を刷る前に、`adapter.gcode`（アダプター）と `body_tube.gcode` から C と E だけを刷り、①ストローがつかめるか ②カチッと止まるか ③リングが回るかを確かめる。

### 光造形を一部にだけ使う理由

| 部品 | 光造形 | 理由 |
|---|---|---|
| 空気口の円盤 | ○（どちらでも可） | 細くなっていく切れ目の先まで形にできる。ねじは軽くしめ、ワッシャーをはさむ |
| 発射塔・葉っぱ | ○（どちらでも可） | 飾りで力がかからない。細い柱・薄い葉がきれいに出る |
| 吹き口アダプター | **×** | 光造形の部品は食べ物・口にふれる用途に向かない（Formlabs の説明）。店の樹脂は水で洗えるタイプでもろい。PETG で刷って、口には市販のストローだけがふれる |
| クリップ・リング・殻 | × | 曲げたりはめたりする所。光造形の樹脂はもろく、割れやすい |
| 火山・社員証の枠 | × | 光造形の台に乗らない |

## 刷る向き・設定

| 部品 | 向き | 設定 |
|---|---|---|
| A 上の殻 | 合わせ面が下 | PETG 0.2 mm・壁 4 周・中 25% |
| B 下の殻 | 合わせ面が下（チームの向き） | 同上 |
| C 前の部屋 | 吹き口の側が下（立てる） | 同上（壁 1.5 mm なので、ほぼ中まで埋まる） |
| E リング・F キャップ | 平らに | 同上 |
| ② ④ ⑤ | ねじ・カップのふち・天井が下 | PETG 0.12 mm・中 100% |
| G・⑥ | 平らに | TPU 95A、ゆっくり（20 mm/s） |
| 案17 の外箱 | 立てる | ふち（ブリム）5 mm |
| ほかの案の部品 | shapes の向き（[../enclosure/shapes/README.md](../enclosure/shapes/README.md)） | PETG 0.2 mm |

PETG の温度はノズル 240 ℃・台 80 ℃（よくある PETG の範囲）。店のフィラメントの箱に書いてある温度と違えば、そちらに合わせる。
